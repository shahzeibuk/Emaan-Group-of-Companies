# Emaan Group of Companies

Marketing site for Emaan Group of Companies: logistics, software, and two residential developments (Emaan Enclave and Emaan Housing). The site is frontend only. The contact form checks entries in the browser and opens an email draft. It does not send data to a server.

## Run locally

```bash
npm install
npm run dev
```

The dev server runs at [http://localhost:3000](http://localhost:3000).

Production check:

```bash
npm run build
npm run start
```

## Pages

| Route | Page |
| --- | --- |
| `/` | Home |
| `/about` | About the group |
| `/logistics` | Emaan Logistics |
| `/soft-tech` | Emaan Soft Tech |
| `/enclave` | Emaan Enclave |
| `/housing` | Emaan Housing |
| `/contact` | Contact |
| `/terms` | Terms and conditions |
| `/privacy` | Privacy policy |

## Replace when you have them

- **Logo.** The header uses a typographic “E” monogram, not a finished brand mark.
- **Postal address and phone.** None are published, because none were confirmed.
- **Registration details.** Terms and privacy name the operator as Emaan Group of Companies and leave registration number, registered office, and governing law for counsel to confirm.
- **Project particulars.** Enclave and Housing are described by character only. Add prices, sizes, dates, or registration numbers only when they can be stated accurately.
